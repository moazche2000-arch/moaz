# تطبيق موطن أونلاين
تطبيق Android 6 فما أحدث، يفتح اللعبة في Trusted Web Activity عبر متصفح يدعمها (Chrome محدث). الحسابات والحفظ والرسومات والمحاكاة من نفس خادم اللعبة. لا توجد نسخة محلية قديمة ولا تخزين لكلمة المرور في التطبيق. يلزم الإنترنت.

الإعداد الأول يبني APK موقّعًا بواسطة مفتاح عشوائي خاص. تُشفّر نسخة احتياطية من مفتاح التوقيع داخل GitHub Actions بمفتاح RSA العام قبل حفظها؛ المفتاح الخاص لفكها محفوظ لدى المالك محليًا ولا يدخل المستودع. لا تعرض مفاتيح التوقيع أو كلمات مرورها في السجلات.

المصدر يستعمل Android Browser Helper الرسمي من Google. مكتبة2.6.2 وGradle8.11.1 وAGP8.9.2. الشيفرة لا تطلب صلاحيات كاميرا أو موقع أو جهات اتصال.

تحديث اللعبة على الخادم لا يحتاج APK جديدًا. تحديث غلاف Android نفسه يتطلب مفتاح التوقيع الأصلي، الموجود في النسخة الاحتياطية المشفرة ومجلد private-runtime المحلي. لا تولد مفتاحًا بديلًا للتحديث.
