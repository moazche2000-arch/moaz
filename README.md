# موطن — مستعمرة الوادي

لعبة مستعمرة ثلاثية الأبعاد بالعربية، مع حسابات وحفظ خادمي ووقت حقيقي.

## النشر المجاني

المشروع في `mawten/`. يستخدم Cloudflare Workers Free وDurable Objects مع SQLite. يحتوي على موارد ونقل وعمال وطرق وجيش وقرى مجاورة. اختصار مهمة واحدة بمقدار600 ثانية مقابل20 ذهبًا، والمالك مجانًا. الدفع غير مفعّل.

بيانات المالك تُضبط عبر أسرار Cloudflare فقط: `OWNER_PASSWORD_SALT` و`OWNER_PASSWORD_HASH`. لا توضع كلمة المرور أو بصمتها في المستودع.

الأسرار تُهيأ قبل مشاركة رابط اللعبة. حدود الاستخدام المجاني تنطبق؛ لا يوجد اشتراك مدفوع مطلوب لهذه التهيئة.
